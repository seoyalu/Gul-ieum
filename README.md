# 굴이음 Gul-ieum

굴 양식장의 수심별 환경을 확인하고 수하연 조절 후보를 검토하는 발표용 웹 앱입니다.
HTML, CSS, JavaScript로 구현했으며 `dist/`에 배포 파일이 있습니다.

## Vercel 배포

1. Vercel에서 **Add New → Project**를 선택합니다.
2. GitHub의 `seoyalu/Gul-ieum` 저장소를 가져옵니다.
3. **Root Directory**는 저장소 루트로 유지합니다.
4. **Deploy**를 누릅니다.

루트의 `vercel.json`이 Framework를 Other로 지정하고, 설치·빌드 없이 `dist` 폴더를 배포하도록 설정합니다.
별도 환경 변수는 필요하지 않습니다. Git 연동 후 `main`에 푸시하면 Vercel에서 다시 배포합니다.

## 로컬 실행 및 점검

`dist/index.html`을 브라우저에서 열면 실행할 수 있습니다.
Node.js가 설치되어 있다면 `node check.cjs`로 주요 기능을 점검할 수 있습니다.

## 프로토타입 범위

센서값과 추천은 가상 시연 데이터입니다. 실제 센서·AI 서버는 연결되어 있지 않습니다.
작업 기록은 각 브라우저의 localStorage에 저장됩니다.

## v3 복합위험 분석 프로토타입
- 고수온 또는 산소 부족을 상황별 핵심 문제로 표시합니다.
- 조절 검토 / 현 배치 유지 / 추천 보류, 일곱 시연 상황을 지원합니다.
- 전체 인양·침하와 하단 단축을 구분하고 해저 여유거리와 작업 범위를 검사합니다.
- 1~7m 가상 관측의 과거 60분 노출시간을 비교합니다. 센서 사이 환경이나 미래 위험을 예측하지 않습니다.
- 기준(28℃ 이상, 산소 3mg/L 미만, 염분 20~35 PSU 밖)은 발표용 가정이며 검증된 굴 안전기준이 아닙니다.
- 학습 AI, 실시간 센서, 공공 관측 API는 연결하지 않은 기준 기반 시연입니다.
- 작업 이력과 시설 설정은 해당 브라우저의 localStorage에 저장합니다. 작업 기록만으로 관측 배치나 효과를 갱신하지 않습니다.
- 검증: `node check.cjs`

기본 시연은 현재 3~5m에서 산소 부족 시 1~3m 전체 인양, 고수온 시 5~7m 전체 침하를 비교합니다. 2m 이동이 가능한 가상 시설을 전제로 하며 실제 관측 추천이 아닙니다. 이전 시설 설정과 혼동하지 않도록 시설 설정 저장 키를 v4로 구분하고 작업 이력은 유지합니다.
